# Cinco preguntas puntuales sobre vacíos del sistema

Estas preguntas están dentro del alcance funcional del sistema y no buscan repetir decisiones que la documentación ya cerró. Están redactadas como dudas que conviene resolver con negocio, fiscal o los responsables de integraciones antes de implementar o liberar.

1. **Cuando un grupo de artículos activa un combo y cada SKU tiene una tasa de impuesto diferente, ¿cómo se debe distribuir fiscalmente el precio del combo entre los artículos para calcular la base gravable y los impuestos de cada uno?**

2. **Si una misma compra cumple simultáneamente varios combos posibles, ¿qué prioridad comercial debe prevalecer: el combo con mayor ahorro para el cliente, el de mayor margen para el distribuidor o un orden configurado por negocio?**

3. **Cuando un obsequio está sujeto a impuesto, ¿el cliente debe pagar ese impuesto adicional aunque el producto sea gratuito, o el distribuidor debe asumirlo sin aumentar el total del pedido?**

4. **Si el cupo de crédito del cliente es suficiente al cotizar pero se agota antes de confirmar por otro pedido, ¿qué experiencia debe recibir el usuario: ofrecer pago en efectivo, recalcular alternativas de carrito o conservar la cotización sin posibilidad de confirmarla a crédito?**

5. **Si el ERP recibe el pedido pero no devuelve confirmación antes de que expire el reintento, ¿qué fuente será la autoridad para resolver el estado final y cómo se corregirá una diferencia entre el historial interno y el ERP?**
