# Definition of Ready

Una historia puede entrar al sprint cuando:

- Tiene un identificador `HU-NN`, actor, objetivo y módulo responsable.
- Tiene criterios de aceptación comprobables.
- Se indica si modifica PHP, JavaScript, la base de datos o la interfaz.
- Se conocen los datos de entrada y salida.
- Se identifica el riesgo de seguridad, especialmente para sesiones y datos personales.
- Se define una prueba manual o automatizada.
- Las dependencias NFC, navegador y HTTPS están identificadas cuando aplican.

No está lista una historia que solo describa una pantalla sin comportamiento esperado.
