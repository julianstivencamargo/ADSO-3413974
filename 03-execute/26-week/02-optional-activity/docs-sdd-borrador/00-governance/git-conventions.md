# Convenciones Git

Ramas:

- `feature/HU-NN-descripcion` para funcionalidades.
- `fix/HU-NN-descripcion` para correcciones.
- `docs/descripcion` para documentación.
- `chore/descripcion` para configuración o mantenimiento.

Commits:

- `feat: crear sesion de asistencia`
- `fix: rechazar asistencia duplicada`
- `docs: actualizar modelo de datos`
- `test: validar serial NFC`

Cada pull request debe indicar historias afectadas, pruebas ejecutadas, cambios de esquema y documentación actualizada.
