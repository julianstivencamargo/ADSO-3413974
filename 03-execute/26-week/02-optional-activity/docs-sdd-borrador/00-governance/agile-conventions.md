# Convenciones ágiles

Cada sprint comienza con historias listas y termina con una revisión funcional.

Ceremonias y resultados:

| Ceremonia | Resultado |
|---|---|
| Planificación | Historias seleccionadas y responsables |
| Revisión | Demostración contra criterios de aceptación |
| Retrospectiva | Mejoras de proceso registradas |
| Revisión técnica | Riesgos de seguridad, base de datos y límites |

Los bloqueos relacionados con lector NFC, tarjetas, HTTPS o navegador se registran como riesgos del sprint.
