# Glosario

| Término | Definición |
|---|---|
| Instructor | Usuario autorizado que administra sesiones |
| Aprendiz | Persona perteneciente a una ficha |
| Ficha | Grupo de formación asociado a aprendices |
| Competencia | Actividad o competencia formativa seleccionable |
| Sesión | Periodo de registro de asistencia |
| Sesión activa | Sesión cuyo estado es `ACTIVA` |
| Serial NFC | Identificador almacenado para reconocer una tarjeta |
| Asistencia | Registro de un aprendiz en una sesión |
| Tolerancia | Minutos configurados al crear una sesión |
| Presente | Estado de asistencia usado actualmente por el endpoint NFC |
| Retardo | Estado previsto para registros posteriores a la tolerancia |
| Ausente | Estado previsto para quien no marca al cerrar la sesión |
