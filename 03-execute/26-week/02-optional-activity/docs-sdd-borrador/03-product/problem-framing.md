# Planteamiento del problema

El instructor pierde tiempo de formación al registrar asistencia manualmente. El proceso puede producir duplicados, errores de identificación y poca trazabilidad sobre quién marcó, cuándo y en qué sesión.

## Afectados

- Instructores que administran sesiones.
- Aprendices que deben registrar su presencia.
- Coordinadores que necesitan verificar asistencia.

## Problema validado por el MVP

El sistema ya permite iniciar sesión, configurar una ficha y competencia, iniciar una sesión, cargar aprendices y registrar asistencias NFC. El alcance restante debe priorizar retardos, ausencias, registro manual, historial y reportes.

## Resultado esperado

Reducir el tiempo de marcación y mantener un registro único, consultable y asociado a la sesión correcta.
