# Visión

Para instructores que necesitan controlar la asistencia de sus aprendices, Asistencia NFC es una aplicación web que permite configurar sesiones y registrar marcaciones mediante tarjetas NFC, reduciendo el tiempo y los errores del control manual.

## Objetivos

| Objetivo | Métrica propuesta | Estado |
|---|---|---|
| Procesar rápido una marcación | 95% en menos de 2 segundos | Por medir |
| Evitar duplicados | 0 duplicados por aprendiz y sesión | Implementado por índice único |
| Mantener trazabilidad | 100% con sesión, aprendiz, fecha y método | Parcial; revisar instructor en NFC |
| Soportar un grupo de formación | Hasta 40 aprendices | Por probar |
| Facilitar seguimiento | Historial y reportes disponibles | Pendiente |
